# Hasin Martial Arts Academy Bareilly

Responsive static website for Hasin Martial Arts Academy Bareilly.

## Website files

- `dist/`: website, styles, scripts, favicon and optimized assets.
- `media-sources.json`: Google Maps business details and owner-uploaded photo sources, checked on 27 October 2026.
- `vercel.json`: serves `dist/` when this repository is imported into Vercel. No build step or dependencies are required.

The current Google listing uses **Hasin Martial Arts Academy Bareilly**, **La Mall, 98, Civil Lines, Bareilly, Uttar Pradesh 243001**, and **+91 84749 17161**. Older search results may still use Indian Martial Arts Academy / IMA and the former B.I. Bazaar address.

Hours and review counts reflect the listing at the time of verification. Class schedules, fees, age groups and holiday hours should be confirmed directly with the academy. WhatsApp links prepare an enquiry; visitors must send it themselves.

The website uses the academy's owner-uploaded Google Maps photos and an original logo created for this update. The original stock hero training video and its matching poster are retained at the owner's request; the gallery and business details belong to Hasin.
